RUNTIME
The converter uses the C++ standard library, Microsoft compiler runtime and
Windows system APIs. It does not link libpff, libpst, pstsdk or a third-party zlib
library. DEFLATE/zlib-format inflation, CRC32 and SHA-256 are implemented in the
project. Python's zlib module is used only by synthetic test/verification code.

# OST2PST privacy policy / 隐私政策

Publisher / 发布者: Kirin Huang · Updated / 更新日期: 2026-11-24

## English

OST2PST converts a file you select on your Windows PC. To make the new PST, the application reads locally available folders, messages, recipients, attachments and other mailbox properties from that file. Conversion requires no account or internet connection. The application has no analytics or advertising SDK and does not send mailbox data, file paths, conversion reports or usage events to the publisher.

The output PST and conversion reports are written to the destination you select. Reports, temporary working files and recovery files may contain identifying information or mailbox data. An interrupted run can leave recovery files beside the destination. These files use the access controls of their Windows locations; the application does not add its own encryption. Choose a folder you control. If you use a shared or cloud-synced folder, its permissions and sync software govern who else can access it. You can inspect or delete outputs and reports at any time after conversion. Delete recovery files only when you no longer need to resume. The source file is not modified.

The GitHub project link and the optional Ko-fi link open the system browser only when you choose them. The links do not include mailbox or file information. The sites may receive ordinary browser connection information such as your IP address. An optional tip is processed by Ko-fi and its payment provider under their own policies; the publisher may receive the supporter details and payment confirmation those services make available. Tipping does not change the application's features. Microsoft separately handles Store acquisition and distribution. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), [Ko-fi's privacy policy](https://ko-fi.com/privacy) and [Microsoft's privacy statement](https://privacy.microsoft.com/privacystatement).

For a privacy question, contact the publisher through the [project's support page](https://github.com/Hyper-Beast/OST2PST/issues). Issues are public: do not post mailbox files, reports, email addresses or private payment details. The publisher cannot retrieve conversions stored only on your PC.

## 简体中文

OST2PST 在 Windows 电脑上转换你选择的文件。为生成新的 PST，程序会读取该文件中已有的邮件、文件夹、收件人、附件及其他邮箱属性。转换不需要账户或联网。程序不含分析或广告 SDK，不会将邮箱数据、文件路径、转换报告或使用记录发送给发布者。

PST 和转换报告保存在你选择的目标位置。报告、临时工作文件和恢复文件可能含有可识别个人的信息或邮箱内容；中断后，目标位置旁可能保留恢复文件。这些文件受所在 Windows 位置的访问权限保护，程序不另行加密。请选择自己可以控制的文件夹；若保存到共享或云同步目录，访问和同步取决于该目录的权限和同步软件。转换后，你可以查看或删除输出与报告；仅在不再需要继续转换时删除恢复文件。程序不会修改源文件。

只有主动点击才会在系统浏览器打开 GitHub 项目页或 Ko-fi 自愿赞助页。链接不附带邮箱或文件信息；网站可能收到 IP 地址等普通浏览器连接信息。赞助由 Ko-fi 及其支付服务商按各自政策处理，发布者可能收到平台提供的支持者信息及付款确认。是否赞助不影响任何功能。Microsoft 单独处理商店获取与分发。相关平台政策见上方链接。

如有隐私问题，可通过[项目支持页](https://github.com/Hyper-Beast/OST2PST/issues)联系发布者。该页面公开，请勿提交邮箱文件、报告、邮件地址或私人支付信息。发布者无法取回仅保存在你电脑上的转换数据。
